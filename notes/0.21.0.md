- **Vibe is no longer held up while its tests wait in line.** When Queue takes a heavy command (a test suite, a build, a typecheck), Vibe gets the run's place in line back at once and carries on; the result is typed into the conversation when the run finishes.

## For agents
- A heavy command Queue's guard takes returns at once with "Queued as <id>"; you'll be notified here when it finishes. Read its output with `queue_wait` or `queue_status` and the id; do not run it again.
