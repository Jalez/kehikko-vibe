- **The skills you write for a kehikko.** Every Vibe session started on that kehikko gets them as its own skills, for that session alone, and is told when to use each.
- **Changes reach running sessions.** A skill you add, change or remove while a session runs is told to it after its next tool call, with where to read the new one.
- **Truthful skill lists.** A module's skill that a session was not given is now said as not loaded in that conversation, instead of as one it has.

## For agents

- Skills the person wrote for this kehikko load into new sessions and are listed in the notes; one added while you run is read with `kehikko_skills` on the kehikko door.
